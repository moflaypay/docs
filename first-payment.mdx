Use this tutorial to go from a new Moflay account to your first sandbox payment with the Node.js SDK.

## Prerequisites

- A [Moflay account and organization](/setup-moflay)
- A sandbox [API key](/setup-api-key) with the `express.pay` permission
- Node.js, pnpm, npm, or Bun

## Step 1: Install the SDK

```bash
npm install @moflay/sdk
```

## Step 2: Store your API key

```bash
export MOFLAY_API_KEY="mof_test_your_api_key"
```

## Step 3: Send a sandbox payment

```typescript
import { Moflay } from "@moflay/sdk";

const moflay = new Moflay({
  token: process.env.MOFLAY_API_KEY!,
});

async function main() {
  const payment = await moflay.express.pay({
    phoneNumber: "254712345678",
    amount: 100,
    description: "Order 1001",
    accountReference: "ORDER1001",
  });

  console.log(payment.paymentId, payment.status);
}

main().catch(console.error);
```

The payment starts in `pending` status after Moflay sends the STK push request.

## Step 4: Check the result

The response includes fields such as:

- `paymentId`
- `transactionId`
- `customerId`
- `status`
- `amount`
- `environment`

After the request succeeds:

1. Open the [Moflay dashboard](https://app.moflay.com).
2. Go to the **Transactions** page.
3. Confirm that the payment appears in the sandbox environment.

## Verify the result

Your setup is working if:

- The SDK call returns a valid payment response.
- The transaction appears in the dashboard.
- The environment is `sandbox`.

## Troubleshooting

- **The API returns `missing_api_key`**: Make sure the SDK receives `MOFLAY_API_KEY`.
- **The API returns `invalid_api_key`**: Check that the key is active and copied correctly.
- **The API returns `invalid_access`**: Add the `express.pay` permission to the key or create a new key with that permission.
- **The payment does not appear in the dashboard**: Confirm you are viewing the sandbox environment.
